What happens

  1. A new Easy-RSA client certificate + private key are generated for this device only.
  2. A static VPN address is reserved (adults {{ cfg.ranges.ADULT[0] }}–{{ cfg.ranges.ADULT[1] }}, children {{ cfg.ranges.CHILD[0] }}–{{ cfg.ranges.CHILD[1] }}, guests {{ cfg.ranges.GUEST[0] }}–{{ cfg.ranges.GUEST[1] }}).
  3. The profile embeds the CA, the device certificate & key and the tls-crypt key; it connects to {{ cfg.public_host }} {{ cfg.public_port }} {{ cfg.protocol }}.
  4. The private key is shredded on the server right after the profile is built. The encrypted profile can be downloaded for a limited time.
  5. Filtering, schedule and firewall rules follow the device by its static address.
Never share one profile between two devices — each device must have its own. Sharing is exactly what makes one of them drop off.
